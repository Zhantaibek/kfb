# Концепции главной страницы

Двенадцать вариантов дизайна главной страницы сайта Кыргызской фондовой биржи. Нужны, чтобы сравнить их и выбрать направление.

Код вариантов лежит в приложении Next.js, а не в этой папке: страницы Next.js работают только внутри `frontend/src/app`. Эта папка — точка входа и описание.

## Как открыть

1. Запустите проект из корня репозитория: `npm run dev`. Перед этим должен работать Docker с базой (`npm run db:up`).
2. Откройте каталог: http://localhost:3000/design-concepts

## Откуда данные

- **Варианты 1 и 5** — макеты с демонстрационными данными из `_shared/mock.ts`. Котировки, новости, события и сообщения эмитентов вымышлены, тикеры и названия эмитентов взяты из списка КФБ. На каждой странице есть пометка о демо-данных. Фото — из `frontend/public` (снимки Unsplash, авторы в `public/hero/CREDITS.md`).
- **Остальные варианты** — на реальных данных сайта: новости и контакты из админки, индекс и итоги торгов из `loadMarketData()`. Новости без анонса (черновики и тестовые записи) не показываются.

Сами варианты к kse.kg не обращаются.

## Анимации

Общий слой для всех вариантов: `_shared/motion.css` (стили) и `_shared/Motion.tsx` (наблюдатель прокрутки), подключены в `layout.tsx`. В разметке анимации включаются атрибутами:

- `data-intro` — первый экран при загрузке: заголовок выезжает по словам (`<Words>`), фото открывается шторкой или медленно приближается, график прорисовывается;
- `data-reveal`, `data-stagger` — блоки и списки появляются при прокрутке, элементы списка по очереди;
- `data-draw`, `data-grow` — мини-графики прорисовываются, полосы диаграмм вырастают;
- `data-count` — цифры считаются от нуля до значения;
- `data-parallax`, `data-tilt`, `data-spotlight` — параллакс фото, наклон карточки индекса за курсором, подсветка карточек под курсором.

Переходы между вариантами — View Transitions (`<ConceptPage>` в `_shared/ConceptPage.tsx`): переключатель сдвигает страницу вправо или влево в зависимости от номера, из каталога вариант «поднимается». Сверху идёт полоса прогресса прокрутки в цвете варианта.

Если в системе включено «уменьшить движение» (prefers-reduced-motion), анимации отключаются и всё содержимое видно сразу. Без JavaScript страницы тоже видны полностью.

## Изменения в основном сайте

Одна строка в `frontend/src/components/SiteChrome.tsx`: на адресах `/design-concepts` сайт не показывает свою шапку, бегущую строку, заставку и подвал и не считает эти просмотры в статистике посещений. Остальной сайт не менялся.

## Как удалить

Удалите `frontend/src/app/design-concepts/`, `frontend/public/design-concepts/` и эту папку, затем уберите условие `isConcept` в `SiteChrome.tsx`.
